# AgentSupplyGuard technical report

[Read the English technical report](docs/TECHNICAL_REPORT.en.md).

This public technical record documents public-evidence assessment, policy actions, uncertainty, and counterevidence. It does not establish independent security accuracy, installed safety, or a new detection advantage. The English report is the only technical-report edition in this snapshot.

The accompanying aggregate files, source hashes, and original license support traceability. With Python 3.10 or later, `python3 scripts/verify.py` checks snapshot integrity and aggregate consistency; it does not replay the original policy or verify security truth. Raw research inputs and the full replay attachment are not included.

This repository publishes a lightweight technical-report snapshot. Source attribution and the name-spelling discrepancy are documented in the report; original copyright notices are preserved. This record does not designate a finalized research-author list. Codex assisted with drafting, translation, source inspection, and checks.
